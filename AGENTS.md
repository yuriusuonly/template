<h1>Agents</h1>

<h3>Runtime configuration</h3>

<ul>
  <li>The runtime source of truth is <code>opencode.json</code>. It loads this file through <code>instructions</code> and selects the <code>0rchestrator</code> agent by default.</li>
  <li>The config enables auto-update notifications, snapshots, and automatic compaction with pruning.</li>
</ul>

<h3>Mandatory instructions</h3>

<ul>
  <li>Follow <code>CONTRIBUTING.md</code> for every new or edited file with its rules and conventions.</li>
  <li>Keep <code>README.md</code> accurate for project composition, setup, usage, and system architecture.</li>
  <li>In the <code>README.md</code> project composition, list directories before files and end directory names with <code>/</code>.</li>
  <li>Keep <code>CHANGELOG.md</code> synchronized with the major changes.</li>
  <li>Commit the change with a one-line message in the same step as every <code>CHANGELOG.md</code> update.</li>
</ul>
