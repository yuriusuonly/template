# Contributing

### Formatting rules

The following rules apply to all files (`*`):

<table>
  <thead>
    <tr>
      <th>Files</th>
      <th>Details</th>
    </tr>
  </thead>
  <tbody>
    <tr>
      <td><code>*</code></td>
      <td>
        <ul>
          <li>Always use 2 space indentation.</li>
          <li>Always use <code>LF</code> end-of-line sequence.</li>
          <li>Always add <code>newline</code> character.</li>
        </ul>
      </td>
    </tr>
  </tbody>
</table>
